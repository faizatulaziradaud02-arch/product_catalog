# Product Catalog App

A Flutter product catalog application developed as part
of the Junior Mobile Developer assessment.

## Features

- Product listing
- Product search
- Product details
- Pagination / Load More
- Pull-to-refresh
- Error handling
- Responsive UI

## Tech Stack

- Flutter
- Dart
- REST API
- DummyJSON

## API

DummyJSON Product API

## How to Run

1. Clone the repository
2. Run flutter pub get
3. Run flutter run
